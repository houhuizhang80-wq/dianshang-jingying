# 电商经营模拟器

经营模拟游戏：仓储、快递、员工、采购、直播、银行、售后、法务、税务、海外、多店铺……从个人小店铺起步，一路经营成规模化电商。

## 在线试玩

<https://houhuizhang80-wq.github.io/dianshang-jingying/>

打开即玩，**手机竖屏体验最佳**（本来就是为手机设计的），桌面浏览器左右会有黑边。

## 本地运行

```powershell
cd 电商经营模拟器
python -m http.server 8766
# 打开 http://127.0.0.1:8766/
```

> ⚠️ **不要用 `file://` 直接打开** —— 浏览器会限制 `file://` 下的 `localStorage`，导致存档丢失。

## 玩法概览

- **开局**：填写店主姓名、店铺名称、选择店铺类型（个人 / 工商户 / 公司）
- **主营**：采购货源 → 仓储上架 → 定价售卖 → 处理订单 → 快递发货 → 售后处理
- **多条业务线**：仓储、员工招聘与排班、银行存贷、税务申报、直播带货、法律纠纷、海外业务、多店连锁……
- **数据看板**：随时看营收、库存、员工效率

## 关于原版

这是用 **HBuilderX 云打包**出的 Android APK（DCloud appid `H529D8F66`，v3.9.0，
包名 `com.dianshang.sim`）的网页源码部分。本仓库为了能直接开 Pages 试玩，
**只保留了网页所需的目录**：

| 原版目录 | 处理 | 说明 |
|---|---|---|
| `index.html` `css/` `js/` `data/` `img/` `assets/` `icon.png` | ✅ 保留 | 网页运行所需 |
| `manifest.json` `androidPrivacy.json` | ✅ 保留 | 应用清单与隐私声明（不影响网页） |
| `server/` | ❌ 排除 | 39 MB 的安卓 APK + 部署工具，与网页运行无关 |
| `tools/` | ❌ 排除 | 仅含一份 `sync_private.py`（DCloud 隐私同步脚本），与网页无关 |

## 网页部署后的妥协

原版为安卓 APK 设计，依赖 **5+（HTML5+）原生 API**（`plus.runtime`、广告、
横竖屏、网络等）。代码里几乎所有 `plus.*` 调用都有 **`typeof plus === 'undefined'`**
兜底（22 处），所以在普通浏览器里也能跑——这是开发者预留好的。但有两个功能
在纯网页下会降级：

1. **激励视频广告**：原版对接穿山甲广告位赚钱。降级后弹窗里点「模拟看完并领奖」
   按钮即可获得等效奖励（开发者故意留的 dev 兜底）。
2. **排行榜**：原版 POST 到 `http://8.163.49.40/api/...`（DCloud 阿里云自托管后端），
   这是私网，**GitHub Pages 访问不到**，排行榜会显示异常但不影响主流程。

## 技术说明

- 单页 HTML5 应用，资源按目录分类加载。
- 资源加载顺序在 `js/app/manifest.js` 里集中配置。
- 存档在浏览器本地（`localStorage`），清缓存会丢档。
